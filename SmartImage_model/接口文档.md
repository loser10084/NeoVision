# 模型端接口文档（前端对接）

## 基础信息

- 服务名称：SmartImage_model
- 基础地址：`http://localhost:5001`
- 数据格式：`application/json`
- 返回格式：JSON

## 通用说明

- 所有接口默认使用 `Content-Type: application/json`
- 鉴权：`POST /api/agent/chat` 需携带 `Authorization: Bearer <token>`

## 接口列表

### 1) 健康检查

- URL：`GET /health`
- 说明：用于服务存活检测

响应示例：

```json
{
  "ok": true
}
```

### 2) 智能体对话

- URL：`POST /api/agent/chat`
- 说明：调用 LangChain 对话模型，支持单轮 prompt 或多轮 messages

请求体（二选一）：

1) 单轮

```json
{
  "prompt": "请总结这份病例的关键点"
}
```

2) 多轮

```json
{
  "messages": [
    { "role": "user", "content": "这是患者情况..." },
    { "role": "assistant", "content": "收到，请继续" },
    { "role": "user", "content": "补充检查结果..." }
  ]
}
```

请求字段说明：

- `prompt`：string，单轮输入
- `messages`：array，多轮对话数组
  - `role`：`user` | `assistant` | `system`
  - `content`：string，消息内容

响应示例：

```json
{
  "content": "关键点如下：..."
}
```

错误响应：

- 400：空输入

```json
{
  "error": "empty prompt"
}
```

- 500：模型调用失败

```json
{
  "error": "model call failed",
  "detail": "具体异常信息"
}
```

## 前端调用示例（fetch）

```js
fetch('http://localhost:5001/api/agent/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ prompt: '请用一句话概括' })
})
  .then(r => r.json())
  .then(data => console.log(data.content));
```

## 环境变量说明（后端侧）

- `OPENAI_BASE_URL`：模型服务地址（占位）
- `OPENAI_API_KEY`：模型密钥（占位）
- `REDIS_HOST`：Redis 地址
- `REDIS_PORT`：Redis 端口
- `REDIS_DB`：Redis DB
- `REDIS_PASSWORD`：Redis 密码（可空）
- `SYSTEM_PROMPT`：系统提示词
